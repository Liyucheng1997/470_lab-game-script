# 地下城助手（Dungeon Brawls / 地下城竞技场）

Steam 游戏《地下城竞技场》的单人辅助：**推荐怎么选、怎么出装，AI 按英雄配流派，按 F8 还能自动玩。**

只看屏幕、模拟鼠标键盘，不改游戏文件、不读写游戏内存。战斗交给游戏自带的「自动战斗 / 自动攻击 / 智能施法」。
自动玩默认只在狂欢模式动手（狂欢模式不上排行榜），不要在联机房间里用。

## 能做什么

- **认英雄**：选英雄界面、开局聊天框、头像下的名字，任一处读到就行
- **英雄 + 流派**：选定英雄后，面板先列出英雄自带技能和属性成长（读游戏数据），再由 AI（Claude）配 3 个流派，点一下切换；按英雄缓存，下次秒出
- **三选一推荐**：遗物 / 主动技能 / 被动技能 / 属性 / 挑战，每张卡打分写理由，推荐的那张下面出现 ★
  - 主动技能用游戏 `activeSkill` 表的伤害参数算 60 秒 DPS
  - 选中流派的核心技能、遗物关键词额外加分
  - 挑战：「爽」挑奖励大的，敢接的危险等级随输赢变化；「稳」只接最安全的
- **波次之间**：列出该买什么（技能书、按流派出装、属性锻造器）、哪个技能没开自动释放
- **自动玩（F8）**：同样的判断直接帮你点——选卡、买书买装备买锻造器、用背包、开自动释放、开下一波、输了重试本波
- **问 AI**：F6 带着当前画面问，或在面板底部打字

## 快捷键

| 键 | 作用 |
| --- | --- |
| F8 | 推荐 / 自动玩 |
| F7 | 风格：爽 / 稳 |
| F6 | 问 AI（看当前画面） |
| F9 | 重新生成当前英雄的流派 |
| F10 | 隐藏 / 显示面板 |

## 安装

前提：Windows 10/11（系统自带简体中文 OCR）、已安装游戏、已装 [Claude Code](https://code.claude.com/docs/en/setup) 并运行过 `claude` 登录（AI 功能用订阅额度，不要 API Key）。

1. 双击 `安装.bat`：建 Python 环境，并从**你自己的游戏目录**提取数值表 `tables.json` 和资料 `game_data.md`
   （这两份是游戏内容，不放在仓库里；游戏更新后重新运行 `.venv\Scripts\python.exe build_game_data.py`）
2. 游戏设置 → 战斗：勾上 自动战斗、自动攻击、智能施法
3. 双击 `启动助手.vbs`，面板出现在游戏画面右侧

## 文件

| 文件 | 作用 |
| --- | --- |
| `assistant.py` | 主程序：识别画面、推荐 / 自动玩、面板 |
| `brain.py` | 打分规则和理由、爽 / 稳、出装清单、商店建议 |
| `ai.py` | Claude：英雄流派、看画面答疑 |
| `screen.py` | 截游戏窗口（PrintWindow）、Windows 中文 OCR、SendInput 模拟输入 |
| `build_game_data.py` | 从游戏安装目录提取数值表 |
| `assistant.json` | 设置（首次运行生成）：自动玩开关、留多少金币、AI 模型等 |
| `data/` | 日志 `assistant.log`、流派缓存 `plans/` |
