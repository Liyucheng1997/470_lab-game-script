# 地下城军师（Dungeon Brawls / 地下城竞技场）

Steam 游戏《地下城竞技场》的单人辅助：**从选英雄开始一路陪着打**——讲英雄、讲地图、配流派、三选一和出装按流派推荐，按 F8 还能自动玩（自己走位、放技能、拾取）。

只看屏幕、模拟鼠标键盘，不改游戏文件、不读写游戏内存。
自动玩默认只在狂欢模式动手（狂欢模式不上排行榜），不要在联机房间里用。

界面是半透明液态玻璃风格的悬浮面板：身后的游戏画面模糊后透上来，卡片带高光边，琥珀色标出推荐。

## 能做什么

| 阶段 | 面板给什么 |
| --- | --- |
| **选英雄** | 点到哪个英雄就讲哪个：定位、近战 / 远程、自带技能怎么用、要点，以及 **3 个常见流派**（全部 47 个英雄都写好了，秒出） |
| **选地图** | 认出地图选择界面，讲每张地图 / 难度是什么、适合谁，按你的英雄和风格推荐难度 |
| **开局** | 从 3 个流派里挑一个（点卡片）。每个流派有核心主动 / 被动、出装顺序、遗物优先、属性优先、**前期 / 中期 / 后期的长线规划**、挑战建议 |
| **三选一** | 遗物 / 主动 / 被动 / 属性 / 挑战每张卡打分写理由，附技能攻略；推荐的那张下面出现玻璃胶囊「★ 推荐这张」。三张都不是流派核心时，建议刷新分最低的那张（刷新次数省着用：主动 / 被动 / 遗物才刷，前中期留 1 次） |
| **技能格满了** | 「请替换一个技能」时比较新技能和 E/R/T 上的三个：明显更强才换掉最差的（流派核心不换），否则放弃 |
| **波次之间** | 该买什么、本阶段该优先什么；前中期还缺核心装备时提醒先攒钱，别把金币全花在锻造器上 |
| **战斗中** | 生命 / 法力 / 压力值、自动战斗正在做什么（进攻 / 风筝 / 撤退 / 找怪）、最近放了什么技能 |

**长远眼光**体现在：
- 打分按波次分阶段：前期赚钱 / 成长类加分（越早拿越赚），后期赚钱类几乎不加分、保命类加分
- 选定流派的核心技能、遗物额外加分；主动格满了还拿非核心主动会顶掉已有技能，扣分
- 前中期给下一件核心装备留钱；上一波压力值顶到 75% 以上，下一次挑战收一收
- 战斗里血线留余量（30% 就撤，被围且掉血快 50% 就撤），压力值高时不管什么流派都先清怪，爆发和变身留给精英 / BOSS

## 自动玩（F8）

波次之间：选卡、买书买装备买锻造器、用背包、开下一波、输了重试本波。开局会等你 20 秒挑流派，不挑就用上次选的（或第 1 个）。

战斗中（`combat.py`，每 0.1 秒一次）：
- **看**：怪头顶的纯红血条（长的是精英 / BOSS）、自己的血条（定位英雄）、底部生命 / 法力条、顶部压力值条
- **走位**（WASD）：近战流派冲进最密的怪堆；远程流派和怪保持流派给的距离，太近边退边横移、太远靠近，走走停停留出普攻；站桩流派等怪过来；撞墙卡住会自动换方向
- **放技能**：按攻略库里每个技能的放法——范围技能等怪聚堆再朝怪堆放、位移技能朝怪最密处放、回血 / 保命技能血低时放、变身 / 增益在怪多或有精英时开、蓄力技能按住再松、留给 BOSS 的只打精英。这几类会关掉游戏的自动释放，由军师挑时机；普通伤害技能仍开自动释放
- **拾取**：附近没怪就按 C 一键拾取

## 快捷键

| 键 | 作用 |
| --- | --- |
| F8 | 推荐 / 自动玩 |
| F7 | 风格：爽 / 稳 |
| F6 | 问 AI（看当前画面） |
| F9 | 让 AI 再配 3 个流派（替换攻略库的） |
| F10 | 隐藏 / 显示面板 |

面板底部也能直接打字问 AI，回车发送。

## 安装

前提：Windows 10/11（系统自带简体中文 OCR）、已安装游戏、已装 [Claude Code](https://code.claude.com/docs/en/setup) 并运行过 `claude` 登录（AI 功能用订阅额度，不要 API Key；不用 AI 也能用攻略库）。

1. 双击 `安装.bat`：建 Python 环境，并从**你自己的游戏目录**提取数值表 `tables.json` 和资料 `game_data.md`
   （这两份是游戏内容，不放在仓库里；游戏更新后重新运行 `.venv\Scripts\python.exe build_game_data.py`）
2. 游戏设置 → 战斗：勾上 自动攻击、智能施法；键位保持默认（WASD 移动，Q 英雄技能，E R T 学来的技能，C 一键拾取）
3. 双击 `启动助手.vbs`，面板出现在游戏画面右侧（可拖动）

## 设置（assistant.json）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `auto_move` | true | 自动玩时自己走位、放技能、拾取；关掉就只交给游戏自带的自动战斗 |
| `hero_key` | `"q"` | 英雄自带技能的按键（游戏默认 Q 格是英雄技能） |
| `skill_keys` | `["e","r","t"]` | 三个学来的主动技能 |
| `build_pick_seconds` | 20 | 自动玩开局等你挑流派的秒数 |
| `only_carnival` | true | 自动玩只在狂欢模式动手 |
| `gold_reserve` | 300 | 买东西时留底的金币 |

## 文件

| 文件 | 作用 |
| --- | --- |
| `assistant.py` | 主程序：识别画面（选英雄 / 地图 / 准备 / 战斗 / 三选一）、推荐 / 自动玩、面板状态 |
| `combat.py` | 自动战斗：看血条、定位、走位、放技能、卡墙脱困 |
| `brain.py` | 打分规则和理由、爽 / 稳、按波次的长线规划、出装清单、商店建议 |
| `kb.py` + `knowledge/` | 攻略库：47 个英雄 × 3 流派、全部技能 / 被动 / 装备的玩法、地图说明；`kb.py --check` 校验名字和格式 |
| `panel.py` + `ui/` | 液态玻璃面板（pywebview）：`glass.css` 材质、`app.css` 布局、`app.js` 渲染 |
| `marker.py` | 三选一推荐胶囊（逐像素透明分层窗口） |
| `ai.py` | Claude：AI 再配流派、看画面答疑 |
| `screen.py` | 截游戏窗口（PrintWindow）、Windows 中文 OCR、SendInput 模拟键鼠 |
| `build_game_data.py` | 从游戏安装目录提取数值表 |
| `data/` | 日志、流派选择记录、AI 流派缓存 |
